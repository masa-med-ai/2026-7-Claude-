# 学会スライド 王道デザイン（Claude Slides 版）

医学系学会の一般演題（7〜10 分の口演）を、気を衒わない王道のデザインで Claude Slides のデッキにする。
ルール全文は `references/design-rules.md`、スライド種別ごとの HTML ひな形は `references/slide-templates.md`、値は `references/tokens.json` にある。**スライドを書く前にひな形を必ず読む。**

## 手順

1. **内容を確定する。** 抄録・原稿・データがあればそれだけを使う。無い数値・文献・共同演者名・機器名・承認番号は `[角括弧]` のプレースホルダにし、最後に一覧で伝える。統計値や引用を作らない。サンプルとして架空データを使うときは各スライドの注記に「架空データ」と書く。
2. **デッキを作る。** アーティファクトのガイドを `intent: slides` で呼び、Slides タイプから新しいデッキを作る。以降は型の指示（ファイルの置き場所、送信順）に従う。
3. **デザインシステムを入れる。** Design System の一覧に「学会スライド 王道デザイン」があれば、それをデッキにインストールする（`tokens.json` を型の指示どおりコピーし、`designSystems` に記録する）。一覧に無ければ、このスキルの `references/tokens.json` の値をそのまま使い、デザインシステムなしで進める。
4. **ロゴを上げる。** `assets/showa-medical-university.png` をデッキのアセットとしてアップロードし、返ってきた URL をそのまま `<img src>` に使う。別の所属を指定されたら、そのロゴ画像を受け取って差し替える。ロゴが無ければ置かない。
5. **フォントを宣言する。** `faces` に `"biz-udpgothic": {"family": "BIZ UDPGothic", "href": "https://fonts.googleapis.com/css2?family=BIZ+UDPGothic:wght@400;700&display=swap"}` を入れる。全スライドの `font-family` は `'BIZ UDPGothic', Arial, sans-serif`。
6. **構成を決めてから書く。** 下の標準構成を出発点に、`order` に全スライド ID を入れた `deck.json` と表紙を先に送り、残りをひな形から 3 枚ずつ書いて送る。
7. **渡す。** リンク、仮定したこと、プレースホルダの一覧を短く伝える。頼まれない限り描画確認はしない。

## 標準構成

| # | タイトル | ひな形 |
|---|---|---|
| 1 | （表紙） | cover |
| 2 | 利益相反（COI）の開示 | text（ロゴなし） |
| 3 | 背景 | text + 引用 |
| 4 | 目的 | text |
| 5 | 方法：研究デザインと対象 | two-column |
| 6 | 方法：患者フロー | flow |
| 7 | 方法：手技・機器 | figure-text |
| 8 | 方法：評価項目 | text |
| 9 | 方法：統計解析 | bullets |
| 10 | 結果：患者背景 | table |
| 11 | 結果：主要評価項目 | bar-chart |
| 12 | 結果：副次評価項目 | table |
| 13 | 考察 | table + 解釈 |
| 14 | 本研究の限界 | bullets |
| 15 | 結語 | text |

- 枚数は発表時間（分）× 1〜1.5 枚。方法は最も質疑が集まるので 1 枚に詰めず分ける。
- 症例報告は 方法/結果 を 症例 → 現病歴 → 現症・検査 → 画像 → 診断・治療 → 経過 に置き換える。
- 内視鏡の症例提示（研究会形式）は黒背景の別スタイル。`references/design-rules.md` の「内視鏡症例報告スタイル」に従う。

## 必ず守るルール

**骨格**
- キャンバスは 1920×1080。section は `background:#ffffff; color:#000000; padding:57px 112px 120px; display:flex; flex-direction:column; gap:0`。
- タイトルは `<h2>` 72px（36 pt）、太さ 400、**中央揃え**、`padding:0 0 57px 0`。**セクション名**を書く（背景、目的、方法：○○、結果：○○、考察、本研究の限界、結語）。主張文はタイトルにしない。
- タイトルの直後に仕切り線：`<div style="height:3px;background:#000000;box-shadow:0 3px 6px rgba(0,0,0,0.18)"></div>`。
- **間隔は空の div で作らない。** エディタが保存時に消す。要素の `padding` / `padding-top` で作る。表の上の間隔は表を包む div の `padding-top` で取る。
- ロゴは 3 枚目以降の全スライドに `position:absolute; left:17px; top:981px; width:504px; height:68px; object-fit:contain`。表紙と COI には置かない。
- **ページ番号は書かない。**

**色**
- 白 `#ffffff`、黒 `#000000`、青 `#1f5aa6`、赤 `#d7000f` の 4 色だけ。**グレー、薄めた色、半透明は使わない。** 注記・出典・表頭も黒で、文字サイズだけ小さくする。
- 強調は青で 1 スライド 1〜2 か所。赤は警告・異常値の 1 か所だけ。青と赤を同じスライドで両方使わない。
- 2 群の図は介入群を青塗り、対照群を白塗り黒枠。

**文字**
- サイズは 7 段階だけ：28 / 36 / 44 / 52 / 64 / 80 / 96 px（= 14 / 18 / 22 / 26 / 32 / 40 / 48 pt）。本文 52px、箇条書き・図の横の説明 44px、表・ラベル 36px、注記・引用 28px、メッセージ行 48px。
- 太字は使わない。例外は引用文献の雑誌名（`<b><i>`）だけ。
- 本文は 7 行まで。改行は語句の切れ目に `<br>` で入れ、行の長さは揃えない。単語・数値と単位・固有名詞の途中で折り返させない。
- **結果の数字は単位より 2 段大きく。** Slides は文中で文字サイズを変えられないので、数字と単位を別の `<p>` にして `display:flex; align-items:baseline; gap:4px` で並べる（数字 64px + 単位 44px。色は揃える）。

**本文の配置（文字が少ないとき）**
- 本文だけのスライドは、本文領域（高さ約 753px）の中で位置を選ぶ：`top` / `upper`（既定。余白を上 1：下 2）/ `center`。
- 本文の高さ ≒ Σ（行数 × 文字サイズ × 行送り）+ ブロック間隔。`upper` は本文ラッパーに `padding-top: max(40, (753 − 本文の高さ) ÷ 3)` px を付ける。`center` は `flex:1; justify-content:center`。
- 合計 3 行以下なら文字を 1 段上げる（52 → 64px）。ブロック間隔は 34px 固定で、間を広げて埋めない。飾りや文字を足して埋めない。

**図表**
- メッセージ行は図表スライドだけ。図表の**下**に 48px、中央揃えで 1 行。本文だけのスライドには置かない。
- 表は必ず `<table>`（PowerPoint にテーブルとして書き出される）。`border-top` と `border-bottom` を黒 3px、全セル中央揃え、36px、表頭も黒・太さ 400。5〜7 行 × 4〜5 列まで。注目させる数値 1〜2 か所だけ青。
- フロー図は枠付きの div と `<x-shape kind="arrow-down">`、文字は `<p>` で置き、編集できる状態にする。箱は黒 2px 枠、塗りなし、角丸なし。
- グラフは棒・軸だけを `<svg>`（黒 2px の軸、グリッドなし）にし、数値・群名・軸の数字は `<p>` を重ねる。
- 注記は `position:absolute; left:560px; top:1003px` に 28px。引用は `right:112px; top:960px`、右揃え、1 文献 1 行、書式は `First Author, et al. <b><i>Journal</i></b> Year`。

**使わないもの**
- 色帯、角丸カード、文章を入れた箱、各文の左の色縦線、セクションタグ、アイコン、KPI タイル、グラデーション、影（仕切り線以外）、絵文字、ストック写真、「ご清聴ありがとうございました」スライド。

## スピーカーノート

各スライドの `<aside>` に、そのスライドで話す要点を 1〜3 文で書く。デザイン上の注意書きは入れない。

## 修正を頼まれたとき

- 変えるスライドだけを読み直して直す。人が手で編集した版が保存されていることがあるので、送信が拒否されたら読み直してから当て直す。
- 「余白が多い」と言われたら、まず配置（`top` / `upper` / `center`）と文字サイズ 1 段上げで対応する。
- 「スライド番号を入れたい」「表を PowerPoint の三線表にしたい」「数字と単位を 1 つのテキストボックスにしたい」と言われたら、Slides の書き出しではできないと伝え、`assets/gakkai-template.potx`（スライド番号プレースホルダ・仕切り線・ロゴ入りのレイアウト）を使った PowerPoint 版の作成を提案する。
